# Навыки разработки

Навыки установлены **для всего репозитория** в `.agents/skills/` и сохраняются в Git вместе с проектом. Они доступны при работе из его подпапок. Правила выбора и применения находятся в корневом [AGENTS.md](../AGENTS.md). Установка не изменяет глобальные настройки других проектов на компьютере.

| Навык                                 | Источник                                                                                | Назначение                                                                             |
| ------------------------------------- | --------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| `unslop`                              | [heydamir/unslop](https://github.com/heydamir/unslop)                                   | Проверка и улучшение визуального качества существующего интерфейса                     |
| `design-taste-frontend` (Taste Skill) | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)                         | Дизайн новых экранов и существенные изменения UI                                       |
| `modern-web-guidance`                 | [GoogleChrome/modern-web-guidance](https://github.com/GoogleChrome/modern-web-guidance) | Современные возможности веб-платформы, доступность, производительность и совместимость |

Установлены полные каталоги трёх навыков со справочниками, примерами, ресурсами и скриптами. У Taste Skill имя в `SKILL.md` — `design-taste-frontend`, поэтому каталог называется так же. Дополнительный навык Chrome Extensions из репозитория Google не устанавливался: maket не является браузерным расширением.

## Версии и обновление

В [sources.json](../.agents/skills/sources.json) записаны URL источников, конкретные Git-коммиты, исходные пути и SHA-256 каждого установленного файла. Используются зафиксированные копии, а не плавающие ссылки или автоматически обновляемые загрузчики.

Для обновления скачайте выбранный репозиторий во временный каталог, изучите изменения, замените соответствующий каталог навыка вместе с ресурсами и лицензией, затем обновите его запись и контрольные суммы в `sources.json`. Не редактируйте upstream-файлы при обычной работе над приложением; особенности maket указывайте в корневом `AGENTS.md`.

Копия unslop сохраняет указание автора Damir Sokolovsky и лицензию CC BY 4.0. Taste Skill распространяется под MIT; Modern Web Guidance — под Apache 2.0. Лицензии находятся рядом с соответствующим `SKILL.md`; дополнительные сведения об авторстве ресурсов сохраняются в исходных файлах навыков.

## Использование

При запросе подходящей задачи агент читает соответствующий `SKILL.md` и нужные справочники. Можно также явно попросить использовать `$unslop`, `$design-taste-frontend` или `$modern-web-guidance`. Если текущая сессия не обновляет каталог навыков автоматически, начните новую сессию в этом репозитории; в текущей сессии инструкции доступны по прямым путям из `AGENTS.md`.

Советы применяются с учётом Apple-стиля maket, существующих компонентов и требований задачи. Установка не запускает переработку интерфейса, дополнительные проверки всего проекта или внешние действия.

Скрипты навыков не подключены к npm lifecycle, Git hooks или запуску приложения. Для Modern Web Guidance upstream описывает CLI `npx modern-web-guidance`; пакет CLI не добавлен в зависимости приложения. Локальные руководства доступны в `.agents/skills/modern-web-guidance/guides/`. Вспомогательные скрипты дизайна используют Node.js и, для снимков экрана, браузер; дополнительные инструменты нужны только для соответствующих задач.

`.agents` исключён из TypeScript-проекта и уже исключён из Docker-контекста. Vendored-файлы навыков исключены из форматирования, чтобы сохранять исходные версии и контрольные суммы. Они не импортируются в веб-приложение или desktop.
