Автономная версия maket. Серверная версия продолжает поставляться отдельно.

- Windows x64: обычный установщик `.exe` и `-portable.exe` без установки.
- Linux x64: пакет `.deb`; portable `-portable.AppImage` или `-portable.tar.gz` (распаковать и запустить `maket`, FUSE не нужен).
- macOS Intel и Apple Silicon: `.dmg` для установки и `-portable.zip`. Portable-архив распакуйте целиком и запустите `maket-portable.command`.

Внутри уже есть приложение, Electron и локальный PostgreSQL 17. Устанавливать Docker, Node.js или СУБД не нужно. Работает без подключения к интернету. При первом запуске автоматически создаётся локальный профиль.

Установленная версия хранит данные в пользовательском профиле `maket-desktop`. Portable хранит их в папке `maket-data` рядом с приложением. Перед переносом папки закройте приложение. Не удаляйте и не заменяйте папку данных при обновлении; перед миграцией на другую версию автоматически создаётся резервная копия базы в `backups`.

Редактор, объектная модель, нотации, поиск, импорт/экспорт и локальный MCP доступны. Публичные ссылки и совместная работа через интернет остаются функциями серверной версии. MCP-клиент на том же компьютере использует адрес из настроек и свой Bearer-ключ.

Сборки пока не имеют сертификатов подписи разработчика и Apple notarization. Windows/macOS могут попросить подтвердить запуск. Для Linux требуется обычная графическая среда, для AppImage — FUSE; архив tar.gz обходит необходимость FUSE. Sandbox Electron включён; на системах с запретом unprivileged user namespaces используйте установленный пакет `.deb` с системным sandbox helper.

Контрольные суммы файлов находятся в `SHA256SUMS`.
